## DirectorLink · Hikvision 1.0.3

Free, open-source Control4 driver for Hikvision IP cameras and NVRs. Part of [DirectorLink Drivers](https://directorlink.io/drivers).

Update both files with **Driver → Add or Update Driver or Agent**. Keep the file names exactly as they are: a browser's `(1).c4z` copy installs as a separate driver. Check the downloads against `SHA256SUMS.txt`.

### Snapshots

- **Pictures at the size each screen asks for.** A grid tile or a touchscreen tile that asks for 320 px now gets a 320 px picture from the camera, a few KB instead of a full-size JPEG. Full screen still gets the whole picture. The driver tests once per camera whether it can scale pictures, and keeps the old behaviour if it can't.
- **Lighter notification pictures:** 1280 px wide when the camera can scale them, so notifications arrive faster.
- **Setup Report** and **Test Snapshot** show the real picture sizes.

### NVRs

- **Dead NVR channels are not added.** Add New Cameras skips NVR channels whose camera is disconnected; **Found On Network** counts them, and they are added once they reconnect.
- **H.264 waits for the camera.** On an NVR channel whose camera is offline, the automatic switch to H.264 now waits until the camera is back, instead of logging an error.

### Hub

- **Check For Updates** (off by default): once a day the hub asks GitHub for the latest release and shows it next to **Driver Version**. Nothing about the home is sent.

### Privacy

The driver talks only to the Hikvision cameras and NVRs on your home network, and to GitHub once a day if you turn on **Check For Updates**. It sends nothing to DirectorLink and collects no usage data.
