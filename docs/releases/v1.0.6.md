## DirectorLink · Hikvision 1.0.6

Free, open-source Control4 driver for Hikvision IP cameras and NVRs. Part of [DirectorLink Drivers](https://directorlink.io/drivers).

Update both files with **Driver → Add or Update Driver or Agent**. Keep the file names exactly as they are: a browser's `(1).c4z` copy installs as a separate driver. Check the downloads against `SHA256SUMS.txt`.

### Hub

- **Check For Updates works again.** The project moved to the DirectorLink organisation on GitHub, and the hub now asks the new address. If the project moves again, the check follows GitHub's redirect instead of failing. Only matters if you turned on **Check For Updates** (off by default).

### Camera

- No changes apart from the version number.
